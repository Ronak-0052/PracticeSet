Amazon Clone Website
This project is a front-end clone of the popular e-commerce platform Amazon India, developed using only HTML and CSS.
The main purpose of this project was to strengthen my understanding of front-end web development concepts and improve my practical implementation skills.

About the Project
The website replicates the basic design and layout structure of Amazon’s homepage, including sections such as:
1.Navigation bar
2.Search bar
3.Product sections
4.Hero banners
5.Footer layout
This project was created purely for learning and practice purposes and is not intended for commercial use.

Technologies Used
=> HTML5
=> CSS3
=> Font Awesome Icons

What I Learned
While building this project, I gained hands-on experience with several important front-end development concepts, including:
>> Proper use of Flexbox and CSS Grid
>> Structuring responsive webpage layouts
>> Working with images and media elements in websites
>> Using external icon libraries such as Font Awesome
>> Improving UI design and styling practices
>> Creating cleaner and more organized code structure

Purpose of the Project
The goal of this project was to practice and improve my front-end development skills by recreating the interface of a real-world website. Projects like this help in understanding modern web design techniques and building confidence in web development.

Future Improvements
I plan to continue building more projects like this to further enhance my skills and become more proficient in front-end development.
